# Conditional contract assumptions

The packet establishes local static relations, not general safety or Rust provenance.

1. **Normal returns and control state.** Each reached callback returns normally to its observed next instruction. Unwinding, faults, nontermination, concurrent mutation and control-flow corruption are outside scope. Callback effects preserve RBP/RBX/R12/R13/R14/R15, RSP and the helper's saved frame/control slots. The original incoming value data and descriptor in `[rbp-0x40]` and `[rbp-0x38]` survive until their reload. These are explicit conditions, not proof of any original Rust trait or ownership discipline.
2. **Valid actually accessed memory.** S has writable bytes at +8/+9 and a valid returnable identity. The prior-error path does not require a usable formatter/name/value because those are not accessed. A nonsticky path additionally needs its actual formatter, destination/method-slot, name slice, value data/descriptor and literal reads to be valid at the time reached. The observed ten-byte state access footprint is not an original size, alignment, type or ABI assertion.
3. **Flat domain.** For the nonsticky route, the sampled mode byte at F+0x12 has bit0x80 clear, and sampled H is 0 or1. This is a local domain restriction. No arbitrary H value, invalid pointer, invalid descriptor index or alternate format mode is qualified.
4. **Aliasing and frame integrity.** S, formatter, destination, name, value data and descriptor may have uncharacterized alias relationships. Applying the contract requires that writes through those aliases do not corrupt the helper's saved/control state or invalidate subsequent required reads. Callback mutations to F/destination/method memory are otherwise not silently ruled out: the three writer sites freshly load their destination and vtable each time. The common state writes occur in the stated order after callback effects.
5. **Stable-writer specialization is extra.** To treat the three writer events as calls to one unchanged writer, separately require preservation of F+0, F+8 and its +0x18 method entry between calls. Stable value dispatch additionally requires the saved descriptor and its +0x18 entry to remain usable. These stronger properties are not established by this helper's bytes. RSI at the value call is the original F pointer, not a snapshot of its contents.
6. **Raw status bytes.** Writer branches test AL zero/nonzero, and earlier writer failures assign raw byte1. The last callback's low EAX byte is copied without an additional flat test. This does not establish the original enum/bool/Result layout or a runtime error type.
7. **Excluded behavior.** The pretty route, helper0x157d000, callback implementations, their output/effects, application-level reachability, rendered text, original nominal types and complete formatter remain unknown. No concrete target instructions or callbacks were executed or emulated, and no component gate or equivalence claim follows from the tooling tests.

The machine-readable record includes these restrictions. Static CFG paths are complete only over the stated bit-clear normal-return domain.
